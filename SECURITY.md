# Security

TL;DR runs inside Claude Code with your permissions. It makes no network calls and starts no processes. It reads the tool calls of your session, and the files Claude edits, to build the TL;DR row and the net diff.

## Report a problem

Don't open a public issue for a security problem. Use [GitHub private vulnerability reporting](https://github.com/kushalBanda/claude-tldr/security/advisories/new), or email kushalbanda265@gmail.com.

Include the version (`claude plugin list`), the Claude Code version, and the steps to reproduce. You get a reply within 7 days.

## Supported versions

Only the latest release gets fixes.
